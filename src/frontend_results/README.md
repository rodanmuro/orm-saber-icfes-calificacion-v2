# Frontend Resultados (5174)

Portal de consulta para estudiantes, separado del dashboard docente.

## Arranque

1. Instalar dependencias:

```bash
cd src/frontend_results
npm install
```

2. Configurar API (`.env.local`):

```bash
VITE_API_BASE_URL=http://localhost:8001/api/v1
```

3. Ejecutar:

```bash
npm run dev
```

Queda en `http://localhost:5174`.
