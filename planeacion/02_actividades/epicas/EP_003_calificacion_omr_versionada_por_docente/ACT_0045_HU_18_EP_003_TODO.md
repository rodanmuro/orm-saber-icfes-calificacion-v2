# ACT_0045 - UI web para tablero de examenes calificados

## Objetivo tecnico
Agregar en el frontend web una pestaña "Examenes calificados" con tabla y modal de detalle.

## Tareas implementables
- [ ] Crear nueva pestaña en el dashboard web.
- [ ] Mostrar tabla con columnas acordadas (Id examen, Version, Nombre examen, Estudiante, Grupo, Timestamp).
- [ ] Agregar accion "Ver" para detalle con respuestas correctas vs marcadas y confianza.
- [ ] Agregar accion "Imagen" para visualizar evidencia del examen.
- [ ] Manejar casos sin grupo o sin imagen con placeholders claros.

## Evidencias esperadas
- UI web navegable con tabla y modales.
- Consumo real del endpoint de intentos calificados.

## Criterio de terminado
El docente puede revisar intentos calificados y evidencias desde el frontend web.
